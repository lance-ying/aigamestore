# dataset — public games

The 10 publicly released games from the AI GameStore project: playable source
code and example gameplay videos.

## `games/` — playable source (10 public games)

`game1/` … `game10/` — self-contained AI-generated HTML5 games. Each folder is a
standalone p5.js / Three.js app; open its `index.html` to play. Art and UX are
recreated in a generic style (no copyrighted assets or branding); game logic is
reimplemented from scratch. Each folder also includes a thumbnail
(`gameN.png` / `thumbnail.png`).

These are the same games evaluated by the harness in `../model evaluation/`.

## `videos/` — example gameplay

`example_gameplay_01.mp4` … `example_gameplay_20.mp4` — 30-second example
gameplay clips (H.264 MP4).
